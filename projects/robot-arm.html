6-DOF Robotic Arm

A mechatronics project combining mechanical CAD, actuator sizing, embedded electronics, servo calibration, and C++ control.

Focus Mechatronics
Tools Onshape · C++ · CMake
Status Prototype

Case study

Mechanical + electrical integration

System goal

The arm was built as a full mechatronics exercise: create the mechanical geometry, determine actuator requirements, wire the electronics, and then write the software needed to command and calibrate each joint.

Add your arm photo or Onshape screenshot here A clean CAD render works especially well as the first visual on this page.

Mechanical engineering

The design work included custom Onshape CAD, a six-degree-of-freedom joint layout, torque calculations, servo selection, clearances, mounting geometry, and iterative prototyping. That mechanical work informed the electrical and control requirements instead of being designed separately.

Embedded control

I used C++ to command the servos and iteratively calibrated each joint around the real physical assembly. The project also became a useful testbed for thinking about safe startup positions, power-supply limits, servo current draw, serial control, and the difference between commanded angle and physical mechanism angle.

3D model

Next iteration

Future versions can move from direct position commands toward higher-level motion: inverse kinematics, trajectory generation, closed-loop feedback, and eventually computer-vision-assisted manipulation.
