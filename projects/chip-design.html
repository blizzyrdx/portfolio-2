Case study

From RTL to processor

Learning digital design from the bottom up

This project starts with intentionally small RTL blocks—counters, registers, combinational logic, state machines, and testbenches—before combining those fundamentals into a processor architecture.

Add a waveform, block diagram, or FPGA photo here Great options are a GTKWave capture, Vivado schematic, or your Basys 3 board.

Verification first

Each module is paired with a testbench so behavior can be verified before moving to hardware. Simulation and waveform inspection make timing, reset behavior, state transitions, and interface assumptions visible before FPGA synthesis.

FPGA prototyping

The design flow then moves into Vivado and an Artix-7 FPGA board. Constraints map logical Verilog ports to physical package pins and define the I/O electrical standard, allowing small modules to be validated against switches, LEDs, clocks, and eventually more complex peripherals.

Long-term architecture

The larger goal is a custom RISC-V-based management processor developed through Verilog, assembly programs, simulation, FPGA verification, and progressively more complete CPU subsystems. This project is also my bridge into deeper computer architecture topics such as pipelines, memory systems, buses, instruction sets, and SoC design.
